# log-watcher

Консольный анализатор access-логов веб-сервера: находит сканирующую активность
без ручных правил — по эвристикам.

## Что умеет
- Парсит access.log: IP, HTTP-статус, путь запроса
- Агрегирует статистику по каждому IP: запросы, ошибки 404, уникальные пути
- Выносит вердикт SCANNER / OK по двум эвристикам:
  - 3 и более ошибок 404 (признак перебора путей)
  - 4 и более уникальных путей (сигнатура фаззинга)
- Устойчив к реальному миру: отсутствует файл, нет прав на чтение, битая кодировка, 
  повреждённые строки в журнале — скрипт не падает, а предупреждает и продолжает работу

## Запуск
```bash
python3 log_watcher.py access.log
```
Без аргумента выводит подсказку по использованию.

## Пример отчёта
```text
45.132.0.87 - SCANNER, 404: 4, unique paths: 4
192.168.1.10 - OK, 404: 0, unique paths: 2
185.220.101.4 - OK, 404: 0, unique paths: 2
```

## Технологии
Python 3, только стандартная библиотека: словари, множества, файловый ввод-вывод, sys.argv, обработка исключений.
